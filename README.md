# Simple-Basic-Calculator

# 🧮 Simple Basic Calculator in Python

A simple command-line calculator built with Python that performs basic arithmetic operations: addition, subtraction, multiplication, and division.

This project is beginner-friendly and demonstrates the use of Python functions, conditional statements, user input, exception handling, and basic arithmetic operations.

## ✨ Features

- ➕ **Addition** — Adds two numbers.
- ➖ **Subtraction** — Subtracts the second number from the first.
- ✖️ **Multiplication** — Multiplies two numbers.
- ➗ **Division** — Divides the first number by the second.
- 🛡️ **Input Validation** — Handles invalid numeric input.
- ⚠️ **Division by Zero Protection** — Prevents division by zero.
- 💻 **Command-Line Interface** — Easy to use in a terminal.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Interface:** Command Line / Terminal
- **Concepts:** Functions, `if-elif-else`, `try-except`, user input, and arithmetic operators.

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python --version
```

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/rifazislam1/Simple-Basic-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Simple-Basic-Calculator
   ```

3. Run the Python program:

   ```bash
   python Simple_Basic_Calculator.py
   ```

   On some systems, you may need to use `python3` instead of `python`.

## ▶️ How to Use

1. Run the program.
2. Choose an arithmetic operation: `+`, `-`, `*`, or `/`.
3. Enter the first number when prompted.
4. Enter the second number.
5. View the result in the terminal.

## ⚠️ Error Handling

The calculator includes basic error handling for:

- **Invalid input:** Displays a message if the entered value cannot be converted to a number.
- **Division by zero:** Displays a warning when the second number is zero.
- **Invalid operation:** Displays a message if an unsupported operator is selected.
